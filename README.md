The XMLWPFToolbox allows running XSLT (3) and XQuery 3.1 and XPath 3.1 with Saxon HE 12, and, for the recent builds, alternatively with the PhoenixmlDb Xslt/XQuery engines/packages.

By default Saxon is used as the engine for XSLT and XQuery in a XMLWPFToolbox window, as indicated by the check mark in the Options -> Saxon Engine menu: <img width="2535" height="1355" alt="image" src="https://github.com/user-attachments/assets/07d33952-6c32-48f2-bb94-7ff9fe0b6437" />


If you toggle this menu the engine for that window is switched to PhoenixmlDb Xslt and XQuery, and the check mark in the Options -> Saxon Engine has vanished: <img width="2535" height="1355" alt="image" src="https://github.com/user-attachments/assets/2025c670-5dcd-473f-9e87-985b46e8d824" />
